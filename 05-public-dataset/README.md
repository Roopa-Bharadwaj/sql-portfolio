# Public dataset project (to come)

A future project built on a public dataset, chosen for a business
question it can actually answer — not for the dataset's fame.

Criteria for picking it:
- Publicly available, with a license that allows this use.
- Big enough for a real analysis, small enough to run anywhere.
- A question a hiring manager would recognise: measurement,
  attribution, or experimentation.

No work data, ever.
